# Adapter: Hosted builders (Webflow, Wix, Squarespace)
> Checked 2026-10-11 against help.webflow.com, support.wix.com and support.squarespace.com. Help articles carry no version number. Platform knowledge, not Google rules.

## Detection
README table (served HTML and headers; no repository).

## Rendering default and options
Platform-served HTML: most RJ checks do not apply. Still relevant: embeds/apps loading text with JS → RJ-01.

## Where title, meta, canonical and robots meta live
- **Webflow**: Page settings › SEO (title, description; field patterns on Collection pages). Global canonical URL in Site settings › SEO (protocol, no trailing slash), per-page override → CI-22.
- **Wix**: page SEO panel (title, description, slug, index toggle; Advanced SEO: canonical, extra `meta`/`link` tags); defaults per page type. Canonical: self by default → CI-22.
- **Squarespace**: page SEO tab; "Hide page from search results" or `noindex` via page header code injection (Core plan and up). Canonicals automatic → CI-10.

## Links and routing
Redirects: Webflow Site settings (301), Wix URL Redirect Manager, Squarespace URL mappings (`/old -> /new 301`, only for deleted pages) → CI-20, CI-49.

## robots.txt and sitemap generation
- **Webflow**: editable robots.txt; auto `sitemap.xml`; "Sitemap indexing" off adds `noindex` and drops the page (a `Disallow` alone keeps it listed) → CI-09, CI-14. "Staging indexing" off for `webflow.io` → CI-38.
- **Wix**: automatic robots.txt (editable, reset to default) and `sitemap.xml` → CI-03.
- **Squarespace**: robots.txt and sitemap automatic, not editable (per their help); Settings › Crawlers can add `Disallow: /` → CI-03.

## 404 handling (true status)
Wix states its 404 page returns `404`; Webflow and Squarespace offer custom 404 pages but do not state the status: check with curl → CI-26. Wix suggests a 301 to the home page or another page; pick the closest equivalent, not the home page → CI-21.

## hreflang and i18n
Webflow Localize puts hreflang in the auto sitemap (manual with a custom one); Wix and Squarespace: not verified against the docs → CI-36, IN-10.

## Structured data hooks
- **Webflow**: page Schema markup field (bind Collection fields per item) or custom code, not both → SD-28.
- **Wix**: presets by page type, up to 5 JSON-LD markups per page; its Site Search app adds sitelinks search box markup, retired by Google → SD-06.
- **Squarespace**: generated by the platform; extra JSON-LD only via code injection *(inference)* → SD-28.

## Common pitfalls (with check IDs)
- Site-wide `noindex` in code injection, or "Block search engine crawlers" left on → CI-10, CI-03.
- Webflow global canonical + GTM canonical → CI-22.
- `webflow.io` / built-in Squarespace domain indexable → CI-38.
- Slug changed without redirect → CI-26, CI-47.

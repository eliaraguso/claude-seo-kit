# fjordly.example

Marketing site of Fjordly, a shift-scheduling app for restaurants and cafés.

- Astro 5, static output, deployed to https://fjordly.example
- Feature pages: `src/content/features/*.md`. The frontmatter `title` becomes the `<title>`, `description` the meta description, `h1` the page heading.
- Other pages: `src/pages/` (home, pricing).
